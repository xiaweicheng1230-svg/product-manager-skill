# 产品文档选择地图

按要解决的问题选择文档。没有决策用途的文档不要为了“齐全”而生成。

| 阶段 | 文档 | 主要回答 | 主要读者 | 典型输入 |
|---|---|---|---|---|
| 机会判断 | 竞品分析 | 市场已有方案怎么做，哪些证据可信，机会在哪里 | 领导、产品、研发 | 官网、说明书、实测、访谈 |
| 机会判断 | 用户与场景分析 | 谁在什么情况下遇到什么问题 | 产品、设计、研发 | 访谈、观察、客服反馈 |
| 机会判断 | 商业画布 | 为谁创造什么价值，成本与收入假设是什么 | 领导、产品 | 市场假设、渠道、成本 |
| 产品定义 | 功能大纲 | 整个产品有哪些功能和边界 | 全项目团队 | 产品定位、场景、竞品 |
| 产品定义 | PRD | 这一版具体做什么，怎样才算完成 | 产品、设计、研发、测试 | 功能大纲、原型、技术约束 |
| 产品定义 | MVP与版本规划 | 首版验证什么，后续按什么顺序扩展 | 领导、项目团队 | 风险、资源、依赖 |
| 方案设计 | 信息架构与用户流程 | 用户从哪里进入，如何完成核心任务 | 产品、设计、研发 | PRD、角色、场景 |
| 方案设计 | UE交互说明或可点击原型 | 每个页面、状态和操作如何表现 | 设计、前端、测试 | 信息架构、品牌规范 |
| 技术对接 | 硬件产品需求 | 硬件名称、用途、使用效果和验收是什么 | 硬件、结构、算法、采购 | 场景、成本、算法要求 |
| 技术对接 | 客户端软件需求 | 手机端、小程序和设备界面做什么 | 客户端、设备软件、测试 | PRD、UE、平台能力 |
| 技术对接 | 平台后端需求 | 账号、设备、任务、数据、权限和接口如何工作 | 后端、设备、客户端 | 数据关系、业务流程 |
| 技术对接 | 接口与数据字典 | 跨端发送什么、返回什么、如何处理错误 | 研发、测试 | 平台需求、设备协议 |
| 开发交付 | 会议纪要 | 做了什么决定，谁在何时完成什么 | 全项目团队 | 会议记录 |
| 开发交付 | 排期与甘特图 | 任务、依赖、里程碑和风险如何安排 | 项目负责人、团队 | 工作分解、资源 |
| 开发交付 | 评审与验收清单 | 文档、功能、性能和安全是否达标 | 产品、测试、研发 | 所有需求和测试结果 |

## 推荐最小文档包

### 新项目立项

竞品分析、用户场景、商业画布、功能大纲、MVP与版本规划、PRD。

### 智能硬件进入选型

PRD、系统架构、硬件产品需求、设备端界面需求、平台后端需求、接口与数据字典、验收清单。

### 手机应用或小程序开发

PRD、信息架构、页面与交互说明、平台后端需求、接口说明、隐私清单、验收清单。

### 已有原型进入研发

用原型提取页面清单、用户流程、页面状态和交互规则，再补齐权限、数据、异常、非功能和验收，不重复制作只讲概念的文档。
