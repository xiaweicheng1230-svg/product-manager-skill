# 公开发布检查清单

公开仓库只放经授权的通用框架、脱敏示例和可公开资产。

## 必查内容

- 公司、客户、供应商和学校的真实名称；
- 员工、儿童、家长、教师的姓名、头像、联系方式和身份信息；
- 微信、云服务、数据库、设备和内部系统的账号、密钥、地址和二维码；
- 家庭网络、设备序列号、日志、测试数据和原始摄像头或声音数据；
- 未公开成本底价、报价、合同、采购、渠道和商业计划；
- 受版权保护且没有再发布许可的模板、截图、图片和竞品内容；
- 公司代码、算法模型、接口细节和安全方案；
- 附件、文档属性、批注、修订记录、隐藏工作表和图片元数据。

## 发布方式

1. 用通用占位符替换项目专有内容，例如 `{{PROJECT_NAME}}`、`{{USER_ROLE}}`。
2. 只保留框架、写作规则和自行创作的空模板。
3. README说明用途、安装方式、目录和示例，不宣称模板适合所有公司。
4. 遵守目标仓库现有许可证；独立仓库必须由所有者明确选择许可证。
5. 提交前检查差异，确认没有把原始内部文档、缓存、临时文件和渲染中间文件加入仓库。
